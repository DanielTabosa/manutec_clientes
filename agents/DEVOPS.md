# DevOps

Consultar somente para Docker, deploy, CI/CD, infraestrutura, ambientes ou Git/release quando necessário.

- Diferenciar desenvolvimento local de produção e conferir dependências do ambiente afetado.
- Preservar credenciais, dados e mudanças existentes; não confundir Git com backup do banco.
- Definir execução, validação e recuperação pertinentes ao escopo.
- Não introduzir contêineres, pipelines, deploy ou alterações globais de configuração por antecipação.

Entrega: mudança operacional autorizada e instruções reproduzíveis, sem comandos sobre ambientes não solicitados.
